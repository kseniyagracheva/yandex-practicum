# Stellar-burgers

Данный проект представляет собой приложение, основная логика которого состоит в загрузке ингредиентов, работе конструктора, создании заказа и авторизации пользователя. 

Проект выполнен с помощью:

1. React
2. Redux
3. TypeScript
4. Redux Thunk (запросы к серверу проходят через усилители)
5. Jest и Cypress (использованы для тестирования)

Проект покрыт тестами, которые проверяют корректность редьюсеров (в том числе добавление, удаление и сортировку ингредиентов, а также загрузку данных). В Cypress настроен перехват запросов с использованием моков, протестирована работа конструктора и модальных окон, включая оформление заказа с подставленными токенами и мок-данными.

Для корректной работы запросов к серверу необходимо добавить переменную BURGER_API_URL в окружение. Сама ссылка находится в файле `.env.example`.
